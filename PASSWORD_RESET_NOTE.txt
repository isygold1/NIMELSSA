NIMELSSA VAULT — PASSWORD RESET NOTES
========================================

ISSUE:
  Password reset emails are not appearing in the user's inbox.

CAUSE:
  Firebase sends password reset emails from a default sender address
  (noreply@<project-id>.firebaseapp.com), which commonly lands in the
  SPAM / PROMOTIONS / JUNK folder instead of the main inbox.

WHAT WORKS:
  1. The "Forgot Password?" UI flow works correctly.
  2. Firebase Authentication API successfully sends the email.
  3. Check your SPAM folder — the email is likely there.

PERMANENT FIX (Firebase Console):
  1. Go to https://console.firebase.google.com
  2. Select your project (NIMELSSA Vault)
  3. Authentication → Templates → Password reset
  4. Under "Customize sender":
     - From name:  "NIMELSSA Vault" (or any friendly name)
     - From email: Use a custom domain email you own/verify
                   (e.g., noreply@yourdomain.com)
     - Reply to:   Same or support email
  5. Save

  After this, Firebase will send from your custom domain instead of the
  default firebaseapp.com domain, and emails should arrive in the inbox.

QUICK FIX:
  - Open the spam/promotions folder in your email
  - Find the email from noreply@<project>.firebaseapp.com
  - Mark it as "Not Spam" / move to Inbox
  - The reset link in that email works normally.

CODE REFERENCE:
  - AuthScreen.kt:  Lines 97-105 handle the forgot password UI flow
  - UserSession.kt: Lines 199-215 send the Firebase API request
